# Province map geometry

`sardinia-provinces.json` contains only the path geometry extracted from the
SVG supplied for this project, `Map_of_region_of_Sardinia,_Italy,_with_provinces-it_(2025-).svg`
(SHA-1 `5df2e6a039492b36c06ae3ac6b0bc25cd719b42e`). Styles and labels are
applied by the React component. The file name corresponds to the
[Wikimedia Commons map](https://commons.wikimedia.org/wiki/File:Map_of_region_of_Sardinia,_Italy,_with_provinces-it_(2025-).svg),
credited there to Vonvikken (original) and Arrow303 (derivative) and described
as released into the public domain. The supplied file has no embedded license
or attribution metadata.

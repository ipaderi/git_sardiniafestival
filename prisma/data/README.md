# Dati comuni sardi

`comuni-sardegna.json` contiene l'estratto della Sardegna dal database dei comuni italiani fornito per il progetto (codice regione ISTAT `20`, aggiornamento indicato nella cartella sorgente: 30 ottobre 2026).

Fonte: [Garda Informatica — Database Comuni Italiani](https://www.gardainformatica.it/database-comuni-italiani). Il dataset è distribuito con licenza MIT; la copia della licenza e la nota di attribuzione sono nel `README.txt` del pacchetto sorgente.

Campi inclusi: codice ISTAT del comune, slug, denominazione italiana, codice e nome della provincia, coordinate, superficie e indicatore di capoluogo. L'estrazione comprende 377 comuni, suddivisi tra i codici provinciali CA, NU, OG, OR, OT, SS, SU e VS presenti nel dataset.
